# executorch_flutter

ExecuTorch on-device ML inference for Dart and Flutter.

| Package | Description |
|---|---|
| [`packages/executorch_flutter`](packages/executorch_flutter) | Flutter plugin: asset loading, web, all platforms. |
| [`packages/executorch_dart`](packages/executorch_dart) | Pure-Dart core: `dart:ffi` inference, no Flutter SDK required. |

Flutter apps want `executorch_flutter`; Dart servers and command-line tools
want `executorch_dart`.

See [`packages/executorch_flutter/README.md`](packages/executorch_flutter/README.md)
and [`packages/executorch_dart/README.md`](packages/executorch_dart/README.md)
for usage.
